## The option values, re-asserted from the portal side

`assert-intake-keys.mjs` asserts that every value a DEFINITION emits resolves against the spellings this
form's engine accepts. This asserts the same thing about what the PORTAL actually holds, because the two
can differ: an option silently dropped or renamed at create time leaves a live property whose stored values
the engine cannot resolve, and the definition file still looks right.
